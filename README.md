# Taggit

Taggit 是一個基於 Node.js 開發的個人本地圖片管理工具，提供標籤、評分、瀑布流瀏覽與全螢幕圖片播放等功能。

該工具專注於「雲端同步友好」以適應 OneDrive、Dropbox 等特殊資料夾。程式本身僅作為殼，所有資料皆保留在本地。運行時，系統僅寫入單一 JSON 紀錄檔，並產生只存在於記憶體的資料庫索引與圖片縮圖，不會更動原始圖片的檔案內容與檔名。使用者可隨時手動在資料夾中增刪圖片，或刪除紀錄檔重置環境。

## 使用流程

1. **Staged**: 在 Tagger 上傳，或直接把檔案丟進收藏目錄的 `images/` 資料夾
2. **Commit**: 在 `/staged` 為每張圖片加標籤、給評分，然後提交，或透過符合格式的 JSON 檔案批次匯入
3. **Browse**: 提交後即可在 `/` 搜尋與瀏覽、在 `/player` 播放、在 `/compare` 比較等
4. **Edit**: 在 `/editor` 調整標籤與評分或者退回至暫存區重新整理

## 安裝與執行

需要 [Node.js](https://nodejs.org/)（建議最新 LTS 版本）。

```bash
npm install           # 安裝依賴
npm run build         # 建置
npm run preview       # 啟動
```

- 執行後於瀏覽器開啟本機服務，系統將自動引導進行首次的目錄設定。
- 可隨時使用 `Ctrl + C` 終止服務，系統在停止前會自動保存當前資料。

## 收藏目錄結構

設定的收藏目錄會自動建立如下結構：

```
<收藏目錄>/
├── images/      # 存放原始圖片檔案（程式不會主動更動其內容與檔名）
└── db.json      # 系統唯一的紀錄檔（所有的標籤、評分與狀態皆持久化於此）
```
